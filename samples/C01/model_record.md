## [S] 현병력 (HPI)

```
62세 여자. 7년 전 불면으로 동네 내과에서 수면제(스틸녹스=졸피뎀 10 mg) 처방받아 복용 시작.
처음 반 알 → 2~3년 전 1알 → 최근 1년 3~4알. 자기 전 복용, 새벽에 깨면 1~2알 추가, 낮에도 가끔 1알(하루 최대 3회).
예전보다 효과 떨어져 2~3시간 만에 깸.
미복용 시 불안, 식은땀, 두근거림, 두통, 손떨림. 여러 번 감량 시도했으나 불면·불안으로 실패.
내과·신경과·정신과 등 여러 병원에서 처방받음. 낮 졸림·멍함으로 집안일 지장, 남편·딸과 복용 문제로 갈등.
장기 복용 위험은 잘 모름. 계속 먹어도 되는지, 줄일 수 있는지 궁금해함.
```

## [A] 근거

```
#1. 수면제 의존 (Sedative-Hypnotic Use Disorder)
- 근거 : zolpidem 10 mg 7년 사용, 내성(반 알 → 1알 → 3~4알, 하루 50~70 mg)과 효과 감소(복용 후 2~3시간 만에 각성)
- 근거 : 미복용·감량 시 금단 양상(불면, 불안, 식은땀, 두근거림, 두통, 손떨림)으로 감량 시도 여러 번 실패
- 근거 : 약물 추구(여러 병원 처방, 주간 추가 복용)와 기능 손상(주간 졸림·멍함, 집안일 지장, 가족 갈등)에도 지속
- 근거 : 진찰상 졸림·반응 지연(+), 불안·초조(+); 의식 명료, 급성 중독 징후(-), MMSE-K 28/30
```

## [A] 감별진단

```
r/o 만성 불면장애 : 7년 전 불면이 선행하나 내성·금단·조절 실패가 뚜렷해 단독 진단으로는 부족. 감량 후 재평가
r/o 갑상선기능항진증 : 두근거림·손떨림·식은땀이 미복용 시에만 나타나고 갑상선 비대(-), PR 76 규칙적, 발한(-), 자세성 떨림(-). TFT로 확인
r/o 약물 관련 인지저하 : 주간 멍함 호소, MMSE-K 28/30 정상 범위, 지연회상 2/3. 진정제 과다 사용으로 설명 가능, 감량 후 재평가
r/o 불안장애 동반 불면 : 불안·초조가 미복용 시에 국한되고 재복용으로 완화되어 금단에 더 부합
r/o 타 진정제 병용 : 여러 병원 처방으로 약물 종류·총량 불명확. 소변 약물 선별검사·처방 내역 조회로 확인
```

## [P] 추가 검사

```
- 소변 약물 선별검사 : 타 약물 병용 확인(zolpidem은 일반 선별검사에서 검출되지 않아 음성이어도 복용 배제 못 함)
- TFT(TSH, free T4) : 갑상선 원인 감별
- CBC, LFT, RFT, electrolyte(Na, K), FBS·HbA1c : 전신·대사 상태, 장기 약물 사용 영향, 감량·대체 약제 선택 기준
- vitamin B12·folate : 멍함·인지 저하의 교정 가능 원인 배제
- ECG : 두근거림·QT 등 약물 조정 전 심장 상태 확인
```

## [P] 치료

```
- 급격한 중단 금지. 오늘은 중단하지 않고 처방 내역으로 실제 복용량 확인 후 동기 강화 면담을 거쳐 합의된 속도로 점진적 감량(1~2주마다 10~25%, 금단증상에 따라 조절)
- 처방 일원화 : 본원 단일 처방, 타 병원 처방 중단, DUR 조회
- 수면위생 교육, 수면일지, CBT-I 연계. 장기 작용 약제 교체·보조 약물은 정신건강의학과와 협의
- amlodipine 유지
```

## [P] 처치 결정

```
- 의식 명료, V/S 안정, 급성 중독·심한 금단 징후 없어 외래 감량 프로그램으로 진행(졸림·반응 지연 있어 당일 운전·위험 작업 회피)
- 정신건강의학과(중독·수면) 의뢰
- 가족(남편·딸)이 감량 과정 지지·복용량 확인하도록 권유
```

## [P] 추적

```
- 1~2주 후 재진 : 검사 결과, 수면일지, 실제 복용량, 금단증상 점검 후 감량 단계 조정. 이후 1~2주 간격 V/S·떨림·주간 졸림·낙상 확인
- 감량 완료 후 MMSE 재평가
- 심한 불안, 경련, 혼동, 환각 시 즉시 내원
```

## [P] 환자 교육

```
- 위험성 : 장기·고용량 수면제는 주간 졸림·멍함, 기억력 저하, 야간 낙상, 다량 복용 시 호흡 억제 위험
- 사용 원칙 : 필요할 때 최소 용량으로 2~4주 단기 사용, 낮이나 밤중 각성 시 추가 복용 금지
- 금단증상 : 갑자기 끊으면 불면 악화, 불안, 식은땀, 두근거림, 두통, 손떨림, 심하면 경련 가능. 혼자 끊지 말고 의사와 천천히 감량
- 감량 계획 : 여러 병원 처방분을 합치면 하루 50~70 mg임을 알림. 오늘 당장 끊지 않고 1~2주마다 조금씩 감량, 힘들면 속도 조절·약제 교체 가능. 본원 한 곳 처방, 정신건강의학과 진료 병행
- 비약물적 수면 개선 : 규칙적 기상, 낮잠 피하기, 오후 카페인 제한, 자극 조절, 주간 햇빛·활동, CBT-I
- 추가 검사 : 혈액·소변 약물·심전도로 몸 상태와 떨림·두근거림·멍함의 다른 원인 확인, 결과에 따라 전문의 진료 필요 가능
```
