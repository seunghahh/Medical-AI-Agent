# N.O.V.A. 2026 공개 샘플 증례

개발용 샘플 증례 3건입니다. 증례마다 폴더가 하나씩 있습니다.

| 파일 | 내용 |
|---|---|
| `case.md`, `case.json` | 시작 정보(환자 첫마디 한 줄과 활력징후), 가상 환자 대본, 진찰 결과표 |
| `model_record.md`, `model_record.json` | 모범 초진기록 (플랫폼 제출 칸 S·O·A·P와 주진단) |

## 읽기 전에

- 실제 진료에서 Doctor Agent가 처음 받는 것은 **시작 정보뿐**입니다. 대본과 진찰 결과표는 가상 환자와 진찰 판정 모델만
  봅니다. 대본에 없는 내용은 가상 환자가 임상적으로 중요하지 않은 범위에서 자연스럽게 지어 답합니다.
- 진찰은 `EXAM` 한 번에 진찰 동작 하나씩 요청합니다. 서버는 진찰 목록을 알려 주지 않으므로, 결과표는 개발과 디버깅
  참고용입니다.
- 모범 기록은 작성 형식과 수준을 보여 주는 예시이며 만점 답안이 아닙니다.
- `model_record.json`의 `S`·`O`·`A`·`P`는 SDK `client.diagnose(note=..., diagnosis=...)`의 `note`와 같은 구조이고,
  `diagnosis`는 주진단입니다.
- 예선·본선 평가 증례는 공개하지 않습니다. 증례는 교육용 가상 사례이며 실제 환자 정보가 아닙니다.
