# Sources and processing disclosure

Verified against the local official downloads and https://nova.snubhai.org/docs/ on 2026-10-11.

- NOVA starter: `run.py`, `nova_sdk.py`, `sample.py`, `requirements.txt`, `local.Dockerfile` copied from the supplied `nova-starter`. SDK was refreshed from the official starter ZIP on 2026-10-11; sample tool is unchanged. The agent adds guideline retrieval, 50-turn budget, exact duplicate rejection, stable retry IDs, observed-only preliminary records and source tracking.
- NOVA devkit: `nova_local.py` refreshed unchanged from the official devkit ZIP on 2026-10-11 (30 minutes, charged invalid SAY/EXAM, empty-completion accounting). Local session/benchmark code subclasses its simulator for stricter missing-data behavior and request deduplication. Neither simulator nor benchmark adapters are part of the server submission.
- Existing `agentclinic-gpt-oss-toy/clinic/data.py` and README were read for schema and separation of observed evidence/gold labels; original code is not imported or changed.
- AgentClinic-MedQA: https://github.com/SamuelSchmidgall/AgentClinic, commit b6fbe22300e99a267a7ac94eaa465ab552eef741. MIT (AgentClinic and upstream MedQA). Schmidgall et al., AgentClinic, arXiv:2405.07960 (2024); Jin et al., MedQA, arXiv:2009.13081 (2020). Extended 215 cases only; 107-case base is not added again. Actor facts and flattened physical findings support local simulation; Objective_for_Doctor, Test_Results and Correct_Diagnosis are withheld from the doctor. Gold diagnosis is retained only for post-run review. Questions/replies may be translated by the local LLM. No training is performed.
- DDXPlus English v2: https://doi.org/10.6084/m9.figshare.22687585.v2. CC BY 4.0. Fansi Tchango et al., DDXPlus, NeurIPS 2022 Datasets and Benchmarks, arXiv:2205.09148. Original train/validate/test splits retained; compressed CSV streamed. B/C/M evidence codes decoded using question/value metadata and declared defaults; pathology/differential withheld. LLM maps a natural-language question to a schema item, then Python returns that patient's value.
- ACI-Bench: https://doi.org/10.6084/m9.figshare.22494601.v1. CC BY 4.0. Yim et al., ACI-BENCH, Scientific Data 10, 586 (2023). challenge_data 207 encounters, original splits. Dialogue is model input; reference note only written after generation. Record-only task, not interactive diagnostic evaluation. No automatic clinical quality score.
- NOVA guidelines: 15,904 Markdown documents mounted at `NOVA_GUIDELINES_DIR` / `/opt/nova/guidelines`. Scalar front matter retained: title, organization, year, language, source_url, license. Complete source text indexed locally in overlapping character chunks using SQLite FTS5/BM25. The designated Doctor API selects complete observed sentences; source IDs and exact quotes are validated before search. Rephrased/invented queries are rejected. Retrieved text is context, never patient observation. Source-specific licenses remain applicable. Some prohibit redistribution of modified content; no corpus or rewritten guideline collection is bundled with this submission.

Original benchmark license files remain in the separately supplied `nova-benchmarks-2026` folders. Data and guideline corpora are not redistributed with this project/submission. Runtime manifests record source and code hashes. Official competition scoring and model pretraining overlap are not evaluated.

- Live Clinic UI: `web/` assets and `clinic/live.py` from the existing local `agentclinic-gpt-oss-toy` project, copied into this folder. Paths/launch commands changed; NOVA client events adapted for patient responses, guideline retrieval, and SOAP output. Original project untouched. No diagnosis-review or scoring service is claimed by this UI.
- Public samples: `nova-devkit/develop.py` and `samples/C01`, `C03`, `C10` copied. Launch code adds live events, retrieval logs and preparation-before-consultation timing. Sample content unchanged.

- Source-bound preliminary SOAP: `grounding.py` copies public opening/vitals and returned question-answer/exam observations into S/O and assessment evidence, normalizing recognized Korean age/weight/height numbers while retaining raw text in audit files. Unasked history remains unknown. Doctor-generated diagnosis/differential labels are hypotheses and P is explicitly prospective. Simple number/negative-claim guards are not comprehensive clinical verification. ACI record-only generation is unchanged.

- GitHub demo: accelerated replay of selected events from the public C10 local run on 2026-10-11 (old 20-minute setting), with the same local UI. No guideline body or new clinical performance result is included.
