# 네이버 Required Skills와 연결하는 실습 순서

## 1. NOVA: 상태와 행동 루프

구현된 실행 경로: `run.py --engine langgraph` → `clinic/langgraph_runner.py`
→ `Encounter.choose` → `Encounter.execute` → 조건부 반복/종료.
`choose`는 의사 모델에 공개된 상태만 전달한다. `execute`는 JSON 행동을 검증하고
환자/진찰 환경에 전달하며 관찰을 증거 원장에 추가한다. 모델 API의 native function
calling은 구현하지 않았다. 현재 방식은 구조화 JSON 행동과 Python dispatcher다.

학습할 부분:
- node: 다음 행동 선택과 실행을 나눈 이유.
- state: 관찰된 사실·음성 소견 원문·UNKNOWN·행동 이력을 보존하는 방식.
- conditional edge: 거절 시 피드백을 받고 재선택하며 DIAGNOSE/오류 시 종료.
- checkpoint: 한 증례 안의 상태 저장과 다른 증례 간 격리.

첫 검증은 데모·테스트이며 실제 모델 성능이 아니다. 이후 모델과 환경을 고정해
plain과 LangGraph가 같은 행동 의미를 유지하는지 소수 사례에서 확인한다.
공식 SDK 입출력·의존성 설치 규칙은 공개 후 맞춘다. 공식 웹의 ASK/60턴과
2026-10-06 개회식 자료의 SAY/50턴이 달라, 이 로컬 예제는 후자를 유지한다.
공식 서버에서 확정하기 전 제출 호환성을 주장하지 않는다.

## 2. DM-CDHNet: 문서 RAG부터

처음에는 환자 원자료 없이 원고 Methods, 공개 논문, 실험 프로토콜과 집계 결과만
선택한다. 문단 단위로 나누고 `document_id`, 버전, 절/페이지, 실험 ID를 붙인다.
임베딩 모델 하나와 Chroma로 인덱싱하고, 검색 문단에 근거한 답변과 출처를 반환한다.
관련 문단이 없으면 근거 부족으로 답한다. 코드에서 읽는 허용 경로를 고정한다.

개발용/테스트용 질문을 분리한다. 정답 문단이 top-k에 포함되는 비율, 수치 정확성,
주장과 출처의 일치 여부를 확인한다. 검색된 문서 안의 명령을 실행하지 않는다.

## 3. 실험 조회와 검증 도구

도구는 세 개로 시작한다:
- `search_documents(query, version)`: 근거 문단과 문서 ID 반환.
- `get_experiment_result(run_id, endpoint)`: 수치·분모·기간·점수 의미·출처 반환.
- `validate_comparison(run_a, run_b)`: 코호트, landmark, endpoint, horizon,
  score semantics, censoring, case coverage가 맞는지 구조화된 이유 반환.

수치는 CSV/JSON에서 코드로 읽는다. DM-CDHNet의 기존 검증 함수를 재사용하되,
대형 추론/학습 스크립트를 도구가 임의로 실행하게 만들지 않는다. 현재 저장된 점수를
2년 누적확률로 이름만 바꾸지 않는다. 약물 시뮬레이션은 관찰된 치료 효과로 설명하지 않는다.

## 4. LangGraph와 평가·PR·CI

질문 해석 → 도구 선택 → 실행 → 검증 → 답변/추가 질문/보류로 연결한다.
비교 대상 실험과 기간은 대화 상태에 저장하되, 지식 검색용 DB와 구분한다.
같은 LLM·질문·문서로 단순 RAG, 고정 워크플로, 동적 도구 선택을 비교한다.

자동 평가에서는 올바른 도구/인자, 수치/분모 정확성, 비교 거절, UNKNOWN 유지,
출처 일치, 대화 조건 유지, 호출 수/지연/비용을 기록한다. 설명 타당성은 사람이
일부 검토한다. LLM 자기 채점만으로 성능을 확정하지 않는다.

Git에서 작은 기능 단위 브랜치 → 변경 이유와 검증을 적은 PR → 실제 동료 리뷰
→ 피드백 반영 → 자동 테스트 통과 → 병합을 반복한다. 혼자 만든 PR이나 자동 코드
생성만으로 동료 리뷰 경험을 주장하지 않는다. 로컬 CI 파일 준비와 GitHub 실행도 구분한다.

RAG는 별도 연구 업무용 확장이다. 대회 제출에 문서/임베딩을 포함할 수 있는지,
네트워크·용량·라이선스·대회 모델 사용 조건은 공식 가이드 확인 후 판단한다.
대회에서 장기 메모리 명목으로 다른 증례의 정보나 정답을 넘기지 않는다.
