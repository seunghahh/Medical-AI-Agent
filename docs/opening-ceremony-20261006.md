# 2026-10-06 개회식 자료에서 확인한 사항

출처: 사용자가 제공한 7장 스크린샷, 발표 슬라이드 11–16 및 18쪽.
아래는 이 toy project의 구현 참고자료이며, 공식 SDK의 통신 규격은 포함되어 있지 않다.
이전 계획에서 사용했던 60턴 기준은 이번 자료의 50턴 기준으로 교체했다.

## 진료와 제출

- 가상 환자 진료 후 SOAP 초진 기록과 주진단 1개를 제출한다.
- 증례당 최대 50턴·20분, DIAGNOSE 제출로 종료한다.
- 시작 정보는 이름·나이·성별·내원 이유와 활력징후이다.
- SAY: 질문·설명·공감, 한 번에 30자 이하, 질문 하나씩, 1턴.
- EXAM: 진찰 동작 하나를 문장으로 요청, 목록 미제공, 1턴. 묶음 요청은 거절하며 턴 차감 없음.
- TEST: 본선에서만 검사 하나를 문장으로 요청, 목록 미제공, 1턴.
- DIAGNOSE: SOAP와 주진단 1개, 0턴.
- 예선 고정 모델: `openai/gpt-oss-20b`, 엘리스 API 제공, 파인튜닝 불가.
- 예선은 대회 모델을 증례마다 최소 한 번 호출해야 한다.
- 세션당 최대 200회 호출, 입력 50만·출력 10만 토큰.

## SOAP

- S: 주호소·현병력·과거력·약물·알레르기·가족력·사회력·계통 문진, 확인한 음성 소견 포함.
- O: 실제 받은 진찰 소견과 획득 턴, 본선 검사 결과.
- A: 주진단 1개·근거·감별진단.
- P: 추가 검사·치료·처치 결정·추적·환자 교육.
- 물어보거나 진찰한 내용을 기록해야 인정되며, 묻지 않고 기록한 내용은 인정되지 않는다.
- 교육 계획과 교육 시행은 다르다. 실제 설명은 진료 중 SAY로 한다.

## 예선 평가 및 제출 환경

- 공개 샘플은 개발용이며 채점하지 않는다.
- 리더보드는 비공개 5증례, 하루 한 번 채점. 최종 평가 10증례.
- 코드 ZIP: 루트에 `run.py`, `requirements.txt`, 50MB 이하.
- 서버 빌드·샘플 검증 후 공식 평가 요청. 팀당 하루 한 번, KST 기준.
- 인터넷 차단, 대회 모델은 대회 서버를 통해서만 호출.
- 제출 페이지 공개 예정일은 슬라이드 기준 10월 10일. 현재 공개 여부는 이 문서에서 확인하지 않았다.
- 팀이 선택한 제출을 GPT·Claude·Gemini로 채점한 평균. 상위 30팀은 3회 이상 평가 예정.
- 개발 크레딧 최대 5만원 상당, 공식 평가·채점 비용은 차감하지 않음.
- 무효 증례(미제출·시간 초과·대회 모델 미호출)는 0점.
- 정보수집 25, 진단추론 15, 검사·추적 10, 안전 15, 의사소통 15, 효율 20점.
- 세부 채점 항목·프롬프트는 비공개. toy의 exact match를 위 배점으로 환산하지 않는다.

## 본선 및 사용 원칙

- 본선 자료: 공개 1·비공개 5·임상의가 새로 만든 문제 3으로 표시됨.
- GPU A6000 48GB 1장, 인터넷 차단, 외부 LLM API 불가.
- 선택·학습 모델 사용 가능, 모델 자산 합계 32GB, 코드 ZIP 50MB 별도.
- 가상 환자·채점 모델 조작을 위한 프롬프트 인젝션 금지.
- 비공개 증례·채점 정보 유출 시도 및 다른 팀 계정·코드·토큰 접근 금지.
- 외부 데이터·모델·도구는 연구 출판 가능한 라이선스와 출처 명시 필요.
- 수상 후보 제출 코드는 운영진 검토 대상.

## 이 구현에서 재현하지 않는 부분

AgentClinic MedQA 사례는 대회 사례가 아니다. 환자 이름은 없으며 일부 사례는 활력징후도 없다.
공개 자료에 적힌 내용 이상으로 정보를 만들어 시작하지 않는다.
환자 응답은 자유 생성 대신 LLM이 원문 근거를 선택하고 Python이 원문을 반환한다.
30자 제한은 Unicode 문자 수로 구현했다. 단일 질문·진찰의 의미적 판단은 모델 선택기에 의존한다.
공식 거절 정책, SOAP 제출 스키마, 통신 규격, 세션 범위와 토큰 계산은 SDK 공개 후 다시 맞춰야 한다.
